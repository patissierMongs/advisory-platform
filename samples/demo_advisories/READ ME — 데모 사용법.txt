보안권고문 데모 샘플 (올인원)
================================

1) 관리자 화면(/admin) → 권고문 처리 → 이 폴더(demo_advisories)를 통째로
   업로드 존에 드래그&드롭하거나 '📁 폴더 업로드'로 선택하세요.
   - 국가정보원/2026-07/…      → 상위 폴더명에서 출처 자동 탐지
   - KISA/…                    → 폴더명에서 탐지
   - NCSC/웹브라우저/…         → 상위 폴더명에서 탐지
   - FSEC-2026-0021 ….pdf      → 파일명 별칭(FSEC→금융보안원)에서 탐지
   - 기타접수/…-001.pdf        → 본문(KrCERT→KISA)에서 탐지
   - 기타접수/…-002.pdf        → 미탐지 → '-' 자동 지정(수동 입력 데모)
   업로드 직후 '출처 지정' 패널에서 후보 클릭 선택(복수 가능)·일괄/개별 적용을 시험하세요.

2) 각 권고문 '처리 →' STEP2 에서 DB 미등록 CVE 의 직접 등록 폼과
   PDF 색상 하이라이트(제품·버전·날짜 — 폼 필드 색과 동일)를 확인하세요.

3) 일괄 해제하려면 CVE 데이터베이스 탭에 피드 파일을 드래그&드롭(또는 파일 선택)해
   반입·적용하세요.
   - cve_feed_demo.json                 : 위 PDF 들의 CVE 12건 (최소 세트)
   - samples/cve_feed_extended_2026-07.json : 위 12건을 포함한 확장 30건 —
     열거/미만(lt·lte)/범위(range)/전체(*) 등 영향버전 규칙 전 형태 포함

4) 자산 매칭까지 보려면 samples/자산관리대장_엣지케이스_샘플.xlsx 를
   자산관리대장 탭에서 가져오세요 — 헤더 시작행 3, 헤더 행 수 2 로 지정.
   제목행·2단 병합 헤더·부서 세로 병합·제품+버전 한 셀·v접두/'알 수 없음' 버전·
   파일 내 중복 자산번호·부서/제품/버전 누락·담당자 통합 셀 같은 현장 엣지케이스가
   기대대로(경고·최신 행 우선·자동 분리·후보 매칭) 처리되는지 확인하는 용도입니다.
