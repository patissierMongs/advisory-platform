보안권고문 데모 샘플 (올인원)
================================

1) 관리자 화면(/admin) → 권고문 처리 → 이 폴더(demo_advisories)를 통째로
   업로드 존에 드래그&드롭하거나 '📁 폴더 업로드'로 선택하세요.
   - 국가정보원/2026-07/…      → 상위 폴더명에서 출처 자동 탐지
   - KISA/…                    → 폴더명에서 탐지
   - NCSC/웹브라우저/…         → 상위 폴더명에서 탐지
   - FSEC-2026-0021 ….pdf      → 파일명 별칭(FSEC→금융보안원)에서 탐지
   - 기타접수/…-001.pdf        → 본문(KrCERT→KISA)에서 탐지
   - 기타접수/…-002.pdf        → 미탐지 → '-' 자동 지정(수동 입력 데모)
   업로드 직후 '출처 지정' 패널에서 후보 클릭 선택(복수 가능)·일괄/개별 적용을 시험하세요.

2) 각 권고문 '처리 →' STEP2 에서 DB 미등록 CVE 의 직접 등록 폼과
   PDF 색상 하이라이트(제품·버전·날짜 — 폼 필드 색과 동일)를 확인하세요.

3) 일괄 해제하려면 cve_feed_demo.json 을 CVE 데이터베이스 탭에서 반입·적용하세요.
   이 파일은 위 PDF 들의 CVE 코드 전체를 커버합니다.
