#   win_amd64 여도 pip 이 uvloop 을 해석하려다 실패하기 때문에(win_amd64 휠이 없다),
#   빌드를 Windows 에서만 할 수 있었다. standard 엑스트라 중 Windows 에서 실제로 쓰이는
#   것만 여기 직접 적어 그 제약을 없앤다 — 이제 어느 OS 에서도 번들을 만들 수 있고,
#   오프라인 휠 수집도 아무 PC 에서나 가능하다.
#
# 런타임 동작은 동일하다: uvloop 은 애초에 Windows 에서 로드되지 않는다.
